## Featured Project

<div align="center">

<h3>Read-Assist</h3>

<p>
  <strong>Read-Assist</strong> is an accessibility-focused audio book platform for visually impaired users.
</p>

</div>

Read-Assist helps users access digital books through **audio**, **Text-to-Speech**, and **QR Code routing**.  
The project focuses on making reading materials more accessible for users who rely on screen readers and audio-based navigation.

### Key Features

- PDF and EPUB text extraction
- Automatic Text-to-Speech audio generation
- QR Code routing for quick mobile access
- Screen-reader-friendly audio player
- Keyboard navigation support
- High contrast accessibility-focused interface
