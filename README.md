## Featured Project

<div align="center">

<h2>♿ Read-Assist</h2>

<p>
  <strong>
    An accessibility-focused digital book and audio learning platform
    designed to improve access to learning materials for visually impaired users.
  </strong>
</p>

<br>

<a href="https://github.com/Ayries18/Read-Assist">
  <img
    src="https://img.shields.io/badge/VIEW%20PROJECT-2563EB?style=for-the-badge&logo=github&logoColor=white"
    alt="View Read-Assist Project"
  >
</a>

</div>

### Key Features

- 📚 PDF and EPUB text extraction
- 🔊 Automatic Text-to-Speech audio generation
- 🔗 QR Code routing for quick access
- 🎧 Screen-reader-friendly audio player
- ♿ Accessibility-focused interface
- 📖 Digital book and audio management
